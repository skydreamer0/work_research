# Esvatin 中文網站與簡報模式設計

## 目標
把現有的 Esvatin 單頁網站升級成中文版主介面，並加入可切換的簡報模式，讓同一份內容同時適合閱讀與展示。

## 選定方向
採用「單頁網站為主，外加簡報模式切換」。

這個方向比維護兩套版面更穩定，因為內容只需要維護一份。平常使用時保留敘事式網站的閱讀體驗；需要展示時，則切換到逐頁式簡報模式，讓每個主題段落都能像投影片一樣呈現。

## 使用情境
- 內部團隊平時閱讀與審閱內容
- 會議中用全頁簡報模式進行展示
- 需要在內部培訓版與保守對外版之間快速比較

## 介面模型
頁面頂部會有兩組切換控制：

- 內容版本：內部培訓 / 保守對外
- 觀看模式：網站模式 / 簡報模式

網站模式下維持滾動閱讀。
簡報模式下改為一頁一頁的 full-screen section 顯示。

## 簡報模式行為
- 每個主內容 section 視為一張 slide
- 顯示目前頁碼與總頁數
- 提供上一頁 / 下一頁按鈕
- 支援鍵盤左右方向鍵切換
- 支援 `Esc` 離開簡報模式
- 在簡報模式下弱化一般導覽，聚焦單頁內容

## 內容與語言
整體介面改為中文為主。

保留必要專有名詞，例如：
- Esvatin
- GSM
- pH

但標題、摘要、導覽、卡片標籤、按鈕、模式名稱與說明文字都改為自然中文，避免中英混搭造成閱讀斷裂。

## 內容切分
簡報模式預計使用以下 7 個主段落作為 slide：

1. 封面與定位
2. 認識 GSM
3. 臨床影響
4. 機轉與組織反應
5. 證據與結果
6. 安全性與訊息邊界
7. 實務重點與總結

## 視覺方向
網站模式延續目前柔和的醫療教育風格。

簡報模式則會：
- 增加單頁留白
- 強化標題層級
- 降低非必要資訊密度
- 用更明確的頁碼與切換控制建立「正在展示」的感覺

## 技術做法
沿用既有靜態網站架構：

- `site/index.html`：加入中文控制列與簡報模式容器
- `site/styles.css`：加入中文版介面樣式與簡報模式排版
- `site/app.js`：加入中文文案、view mode state、slide navigation 行為

## 驗證
需要補充驗證腳本，至少確認：

- 存在中文模式控制文案
- 存在簡報模式切換文案
- 存在簡報頁碼或簡報導航標記
- JavaScript 包含網站模式與簡報模式的切換邏輯
